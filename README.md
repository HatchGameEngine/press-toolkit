# Hatch press toolkit

![Hatch](https://cdn.tohoku.ac/hatchbg2.jpg)

This is a branding toolkit created by [Alexander Nicholi][nich] for the
Hatch game engine. Several pre-renders in common aspect ratios are
provided as PNGs in this repo for convenience. The PSD is provided so
one can create new renders at any desired aspect ratio, size, quality
and file format. To keep the repo size to a minimum, we will not accept
additional renders in pull requests.
